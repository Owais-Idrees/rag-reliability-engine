# BM25 lexical retrieval

BM25 is a lexical ranking algorithm that scores documents using query term frequency, inverse document frequency, and document-length normalization. It is a strong transparent baseline for retrieval systems and does not require an embedding model.

Lexical retrieval works well when queries and documents share important terms. It can miss semantic matches that use different vocabulary. Hybrid retrieval combines lexical and vector scores, while reranking applies a stronger model to a smaller candidate set.
